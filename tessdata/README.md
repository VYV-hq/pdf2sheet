Place Tesseract language packs here (`TESSDATA_PREFIX` points at this directory):

- `eng.traineddata`
- `kor.traineddata`
- `kor_fast.traineddata` (copy of tessdata_fast `kor.traineddata`)
- `osd.traineddata`

Also copy `configs/` from the system tessdata tree (for example
`/usr/share/tesseract-ocr/5/tessdata/configs`).
